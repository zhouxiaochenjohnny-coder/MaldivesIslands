# 马代选岛

独立的马尔代夫选岛工具。纯静态网站，无需构建，双击 `index.html` 即可打开。

## 功能

- 智能选岛：6 步问卷（同行人、预算、晚数、偏好、落地时间、晕船），输出带理由、风险提示和两人总价估算的排序推荐。
- 全部岛屿：40 座岛，按交通、浮潜、沙滩、餐标、等级、价格、人群、环礁、酒店集团筛选，并支持排序。
- 岛屿对比：最多 3 座并排对比。
- 选岛知识：交通、屋礁、全包、餐标、水屋、季节，每条配大白话、案例和「反过来看」。

## 目录

- `index.html`：页面结构
- `css/style.css`：样式，遵循 Apple HIG，页边距 1.5cm，支持深色模式
- `js/data.js`：岛屿数据与置信度说明
- `js/app.js`：问卷、打分、筛选、对比逻辑

## 数据置信度

| 字段 | 置信度 | 说明 |
| --- | --- | --- |
| 环礁、上岛方式 | 高 | 长期稳定 |
| 交通时长、屋礁与沙滩评分、儿童政策 | 中 | 近似值或编辑主观评分 |
| 酒店等级、集团、餐标 | 中 | 行业通行叫法，无官方统一评级 |
| 价格档位、上岛交通费、总价估算 | 低 | 随季节、房型与运营商大幅浮动 |

全部数据为编辑整理，未经酒店官方核验。上线前建议逐条复核 `verify` 字段。

## 本地预览

python3 -m http.server 8000
