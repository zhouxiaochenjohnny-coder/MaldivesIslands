# 马代选岛

独立的马尔代夫选岛工具。纯静态网站，无需构建，双击 `index.html` 即可打开。

## 功能

- 智能选岛：5 步问卷（同行人、预算、偏好、落地时间、晕船），输出带理由和风险提示的排序推荐。
- 全部岛屿：搜索、筛选（快艇可达、屋礁、全包、亲子、价格档位）、排序。
- 岛屿对比：最多 3 座并排对比。
- 选岛知识：交通、屋礁、全包、水屋、季节，每条配大白话、案例和「反过来看」。

## 目录

- `index.html`：页面结构
- `css/style.css`：样式，遵循 Apple HIG，页边距 1.5cm，支持深色模式
- `js/data.js`：岛屿数据与置信度说明
- `js/app.js`：问卷、打分、筛选、对比逻辑

## 数据置信度

| 字段 | 置信度 | 说明 |
| --- | --- | --- |
| 环礁、上岛方式 | 高 | 长期稳定 |
| 交通时长、屋礁与沙滩评分、儿童政策 | 中 | 近似值或编辑主观评分 |
| 价格档位 | 低 | 随季节与房型大幅浮动 |

全部数据为编辑整理，未经酒店官方核验。上线前建议逐条复核 `verify` 字段。

## 本地预览

python3 -m http.server 8000
